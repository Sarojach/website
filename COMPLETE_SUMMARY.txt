█ QUICK REFERENCE
═══════════════════════════════════════════════════════════════════════════

Start Development:
    $ python backend/app.py
    → Backend on http://localhost:5000
    → Frontend on http://localhost:3000

Test Contact Form:
    1. Fill out form
    2. Click submit
    3. See "Message sent successfully!" (connects to real API!)

Using Admin API:
    curl -H "X-API-Key: dev-admin-key-..." http://localhost:5000/api/contacts

API Endpoints:
    Public (no key):     GET /api/projects, /api/skills, /api/experiences
    Public (no key):     POST /api/contact
    Admin (need key):    GET /api/contacts, POST /api/projects
    Admin (need key):    PUT /api/projects/<id>, DELETE /api/projects/<id>
